---
title: 'List Agent Tasks'
openapi: 'GET /api/v1/vendors/{vendorId}/organizations/{organizationId}/agents/{agentId}/tasks'
deprecated: true
---

<Warning>
Agent tasks are deprecated. Use [planned sessions](/api-reference/sessions-planned/list) instead. A task ID is the same ID as the planned session ID.

[List Planned Sessions](/api-reference/sessions-planned/list) covers the whole organization. Pass the agent ID as the `agentId` query parameter to list one agent's plans. Each plan returns the task's `userValues` as `parameters`.
</Warning>
